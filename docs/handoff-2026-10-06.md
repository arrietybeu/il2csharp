## Standard procedure (one compile-gate slice)

1. **Branch/worktree.** New branch off the chain tip; work in a
   worktree under `%TEMP%\opencode\wtNNN`, never on `main`.
2. **Probe first.** Census the error family on the latest gate tree
   (`work/cgate/sample.py`, `work/cg8/names.py`, `work/cgate/undecl.py`)
   and disassemble representative natives (`work/cg8/disva.py`). Write
   down the native proof before coding (P4: "compiles" never outranks
   "correct"; decline by default).
3. **Patch.** `il2cpp/*.py` are CRLF no-BOM: change them only through a
   script using `work/cgate/patchlib.py` (`patch(path, old, new)` asserts
   CRLF and an exact match count). Keep each script
   (`work/cg8/patchNNN*.py`) so the slice is reproducible. Docs and
   `tests/*` are LF (the e-MCP `write`/`edit` tools are fine there).
4. **Tests.** Portable test (synthetic bytes / fakes) plus a game test
   pinning one native-proven method. `$env:PYTHONHASHSEED='0'`.
5. **Build.** `python work/cg8/build10.py <worktree> work/cg8/bN`
   (10 detached per-group builds, `--strict --publicize --raw-addr`;
   `--workers` is unusable here). mscorlib's group takes ~15-20 min;
   each `split/gK.done` holds `exit seconds`.
6. **Gate.** `python work/cg8/gate.py work/cg8/bN` (merge split -> flat,
   rgate, `cmp.txt` vs cg7 / `cmp_base.txt` vs r_base; pass a second
   argument for another base log). Then
   `python work/lib/tree_brace_audit.py work/cg8/bN/flat`.
7. **Review the delta, not just the total.** Any parse-level code that
   rises (CS1002/1003/1026/1040/1525...) blocks landing -- find the line
   and fix it. Sample new type errors and confirm they are newly
   *visible* (an undeclared name used to mask them), not newly wrong.
8. **Suites.** Portable `python -m pytest -q tests`; game suite with
   `IL2CSHARP_METADATA` / `IL2CSHARP_BINARY` pointing at the main
   checkout's `testgame` and `PYTHONPATH='.;tools'`:
   `python -m pytest -q tests -k game --disable-warnings -rf` (~12-15
   min). Diff the FAILED set against the previous run
   (`%TEMP%\opencode\p126\game_wt131.out`, `work/cg8/game132.out`);
   read every moved golden/pin and record the review in `docs/todo.md`.
   Never re-pin without the user's call.
9. **Hygiene.** `python -m compileall -q il2cpp`; CRLF / no-BOM check on
   `il2cpp/**/*.py`.
10. **Docs + commit.** `docs/todo.md` top section (fix entry, gate
    numbers, moved pins), `AGENTS.md` "In flight", this handoff; commit
    on the branch. No push / merge / promote without the user.
